# Estructuras: cómo detectar la estructura real de un contenido

No hay una estructura "correcta". Para analizar un contenido se lo divide en
**tramos** (beats) en el orden en que aparecen, se le pone a cada tramo el tipo
que mejor lo describe y recién después se mira si coincide con algún arquetipo
conocido. Si no coincide con ninguno, se describe la secuencia tal cual:
eso también es un hallazgo.

## 1. Tipos de tramo

| Tipo | Qué hace | Cómo se reconoce |
|---|---|---|
| gancho | Frena el scroll | Primeros 1–3 s, primer slide, primera línea |
| promesa | Dice qué se va a obtener | "Te muestro…", "Al final vas a…" |
| problema | Nombra un dolor | Síntoma, frustración, costo |
| contexto | Sitúa la escena | Quién, dónde, cuándo |
| tension | Sube lo que está en juego | "Y ahí empezó el problema", cifras que crecen |
| loop | Abre una pregunta que se cierra después | "Pero lo peor fue…", "El tercero es el que más importa" |
| desarrollo | Explica o muestra el cómo | Pasos, demostración, explicación |
| item | Unidad de una lista | "1.", "Segundo error", un slide por ítem |
| ejemplo | Caso concreto | Nombres, números, situación real |
| prueba | Respalda lo dicho | Dato, antes/después, testimonio, demostración |
| giro | Cambia la expectativa | "Pero en realidad…", revelación, remate |
| payoff | Cierra la promesa o el loop | La respuesta, el resultado |
| valor | Lo que se lleva la persona | Regla, checklist, precio, criterio |
| cta | Pide una acción | Guardar, comentar, compartir, DM, link |
| remate | Cierre emocional o humorístico | Chiste final, frase memorable |

Para cada tramo se anota: **orden, tipo, contenido (cita o descripción), duración o slide, y qué retiene** (por qué alguien sigue).

## 2. Arquetipos frecuentes (para comparar, no para forzar)

| Arquetipo | Secuencia típica | Cuándo rinde |
|---|---|---|
| Problema → solución (PAS) | gancho(problema) → tension → desarrollo → valor → cta | Educativo con dolor claro |
| Lista | gancho(lista) → item × N (el más fuerte al final o en el medio con loop) → cta | Carruseles, guardados |
| Historia con giro | gancho(en medio de la acción) → contexto mínimo → tension → giro → remate/valor | Casos reales, humor |
| Mito vs realidad | gancho(contrarian) → creencia → prueba → realidad → valor | Romper creencias del rubro |
| Antes / después | gancho(resultado) → antes → proceso → después → cta | Trabajos visibles (oficios) |
| Tutorial | gancho(resultado o problema) → pasos → payoff → cta | Valor práctico |
| Error común | gancho(error) → por qué pasa → costo → cómo evitarlo → cta | Educativo, compartible |
| Comparación | gancho(pregunta) → opción A → opción B → criterio → veredicto | Decisiones de compra |
| POV / identificación | gancho(situación) → escalada de detalles reconocibles → remate | Humor, comunidad |
| Revelación de precio | gancho(pregunta de precio) → rango → qué lo cambia → cómo no pagar de más | Muy guardable para clientes |

## 3. Cómo reportar la estructura

```
ESTRUCTURA DETECTADA: Historia con giro (variante: sin contexto inicial)
1. [0–2 s] gancho — "…" — retiene porque…
2. [2–6 s] tension — "…" — …
3. [6–14 s] giro — "…" — …
4. [14–18 s] valor — "…"
5. [18–20 s] cta — "…"
DÓNDE SE CAE LA RETENCIÓN: tramo 2, porque…
```

Si la secuencia no encaja: `ESTRUCTURA DETECTADA: propia — gancho → item → item → giro → cta`.

## 4. Señales de retención por tramo

- Un **loop abierto** (pregunta sin responder) sostiene hasta que se cierra: cuanto más tarde se cierre sin aburrir, mejor.
- Un **cambio de atención** (plano, texto en pantalla, ejemplo, giro) cada 2–4 segundos en video o en cada slide en carrusel evita la caída.
- La retención se cae cuando: se repite la idea, hay contexto antes del conflicto, el valor se adivina, el slide tiene texto denso, o el CTA aparece antes del payoff.
